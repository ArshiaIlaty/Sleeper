## Figures (§2.2 Dataset characteristics)

Generated by `scripts/eda/make_figures.py` (reads `eda/per_recording.csv` +
`eda/dataset_stats.json`) with an Edwards-brand palette validated by the dataviz
color checks. Regenerate after any EDA change. These use **real, verified**
dataset numbers — unlike the model-performance `[FILL]` cells.

- `fig1_age_prevalence` — CI prevalence vs age band (the confounder the metric discounts)
- `fig2_site_prevalence` — prevalence per site vs cohort mean
- `fig3_stage_composition` — mean sleep-stage % across the cohort
- `fig4_ci_vs_noci` — sleep metrics stratified by CI status
- `fig5_montage_heterogeneity` — distinct channel montages per site
- `fig6_data_completeness` — field/modality completeness

## Headline contribution to highlight

The paper derives the **Bayes-optimal decision rule** for the Challenge reward:
**predict positive iff `q > p(age)`** — the calibrated probability exceeds the *age-specific*
prevalence. The current code (`team_code.py::_reward_optimal_threshold`) uses the *global*
prevalence; switching to the age-specific threshold is the top-priority, theory-backed
improvement for the official phase.
